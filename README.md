# Прайд

Репо: https://github.com/diadieva/pride · Сайт: https://diadieva.github.io/pride/

Вебплатформа підтримки врятованих тварин реабілітаційного центру «Прайд» (Миколаївщина). Знайомтеся з тваринами та їхніми історіями, підписуйтеся на оновлення та підтримуйте опікунством над конкретною твариною або донатом центру.

**Головне**
- Каталог і профілі тварин: історії, фото, стрічка оновлень.
- Підписка на новини через email, Telegram-бот або Instagram.
- Разові та регулярні донати: Monobank-банка, український еквайринг, Stripe.
- Кабінет «Мої улюбленці»: керування підписками та платежами.
- Мови: українська та англійська. Підхід mobile-first.

**Стиль:** Playful Editorial × Bold Branding × Pop Art. Теплий, яскравий, живий, без тиску на жалість.

**Стек:** Next.js · TypeScript · Tailwind · Supabase · Vercel.
